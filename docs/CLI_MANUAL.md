# Wallep Command-Line Manual

## NAME
`wallep` — Native macOS Live Wallpaper Engine

## SYNOPSIS
`wallep [COMMAND] [OPTIONS]`

## COMMANDS
* `list`: Print all 5,000+ available wallpapers with resolutions and categories.
* `set <id_or_path>`: Apply a wallpaper by ID or local video file path.
* `pause`: Suspend background video decoding.
* `resume`: Resume background video decoding.
* `status`: Inspect connected displays and AC/Battery power state.
* `--help`, `-h`: Display help options.
* `--version`, `-v`: Display application build version.
