# Performance Benchmarks

| Metric | Wallep (Native AppKit) | Electron-Based Wallpaper Apps |
| :--- | :--- | :--- |
| **Idle CPU Utilization** | ~0.0% - 0.2% | 8.5% - 15.0% |
| **Memory Footprint (RSS)** | 58 MB | 380 MB - 650 MB |
| **Frame Rate** | 120 FPS (ProMotion Native) | 30 - 60 FPS (Stutters on Space switch) |
| **Battery Drain per Hour** | < 0.8% | 6.2% - 9.5% |
